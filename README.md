# Tomatobot
Avance Proyecto 1 - Chatbot para un negocio de importaciones desarrollado con Python y NLTK.
# Este proyecto contiene 3 archivos .py Identificar intenciones, Procesador Texto e Intenciones y un main
# el cual ejecutara el código
# El Tomatobot funciona como un menú donde la persona puede ingresar número de opción o la pregunta 
# que el cliente desee ingresar, de esta manera reconoce número de opción y oraciones para consultar información
# La forma de ejecutar el main es primero instalando la librería NLTK, después importando la librería util y os
# posteriormente se carga los 2 modulos antes mencionados
# después se crean los objetos y finalmente se ejecuta el main
